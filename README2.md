Descripción del Proyecto
PokeDex es una aplicación web estática desarrollada con HTML, CSS y JavaScript. El contenido visual fue desarrollado por PumasLab y el despliegue fue realizado por el equipo de ingeniería de Pueblo Paleta Inc. utilizando Azure Static Web Apps con el recurso llamado poquedexvc.

Creación de la Cuenta en Azure

Se ingresó al portal de Azure en https://portal.azure.com con una cuenta personal de Microsoft.
Se registró la cuenta personal ingresando el correo y la contraseña.
Se completó el formulario con el nombre completo, país y número de teléfono para verificación.
Se ingresó el código de verificación enviado por SMS.
Una vez dentro del portal, se procedió a redimir los 200 dólares en créditos gratuitos que ofrece Azure para cuentas nuevas.
Se aceptaron los términos y condiciones del período de prueba gratuito.
Se confirmó que la suscripción quedó activa con los créditos disponibles en el panel principal del portal.


Creación del Repositorio en GitHub

Se ingresó a https://github.com con la cuenta personal.
Se hizo clic en el botón New para crear un nuevo repositorio.
Se asignó el nombre pokedex al repositorio.
Se configuró como repositorio público.
Se hizo clic en Create repository y el repositorio quedó creado y listo para usarse.
